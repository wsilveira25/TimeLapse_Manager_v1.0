Preparação da rede e do certificado

  1. Registre um domínio ou subdomínio com seu provedor DNS. Crie um registro A para o IPv4 público da rede. Só mantenha um registro AAAA se o servidor também for alcançável por IPv6.
  2. No roteador, encaminhe TCP 80 e 443 para o endereço local deste servidor. Libere as mesmas portas no firewall do servidor. Não exponha a porta 8000 à Internet.
  3. O instalador Linux instala o Caddy automaticamente. Em instalações manuais/antigas, instale-o pelo guia oficial para Debian/Ubuntu. Ele solicitará e renovará o certificado Let's Encrypt quando DNS e portas estiverem acessíveis.
  4. Depois que o DNS estiver propagado, execute como administrador do servidor o comando abaixo para ativar o proxy HTTPS e o callback OAuth.
Comando de ativaçãoSalve o domínio para gerar o comando.

Se o provedor bloquear as portas de entrada ou a conexão usar CGNAT, o desafio HTTP do Let's Encrypt não funcionará. Nesse caso, será necessário um IP público/encaminhamento válido ou configurar um desafio DNS no provedor.
