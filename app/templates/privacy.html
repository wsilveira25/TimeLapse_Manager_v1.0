Política de Privacidade

Timelapse Manager · Última atualização: 18/10/2026

1. Sobre o aplicativo

O Timelapse Manager é um software auto-hospedado que captura imagens de câmeras configuradas pelo próprio usuário, gera vídeos timelapse e, opcionalmente, envia esses arquivos para serviços de armazenamento escolhidos por ele (como o Google Drive).

2. Dados que acessamos

Ao conectar o Google Drive, o aplicativo solicita apenas o escopo drive.file, que permite criar e gerenciar somente os arquivos e pastas criados pelo próprio aplicativo. Não temos acesso aos demais arquivos do seu Drive, nem a e-mails, contatos ou outros dados da sua conta Google.

3. Como usamos os dados

Os dados de acesso (tokens OAuth) são usados exclusivamente para enviar e organizar os vídeos e imagens gerados pelo aplicativo na conta do usuário. Não utilizamos esses dados para publicidade, perfilamento ou qualquer outra finalidade.

4. Armazenamento e segurança

Credenciais, tokens, imagens e vídeos ficam armazenados no servidor operado pelo próprio usuário. Não são enviados a terceiros, exceto ao provedor de armazenamento que o usuário decidiu conectar.

5. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros.

6. Uso dos dados da API do Google

O uso e a transferência de informações recebidas das APIs do Google pelo Timelapse Manager obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Revogação e exclusão

O usuário pode desconectar a conta a qualquer momento no painel do aplicativo e revogar o acesso em myaccount.google.com/permissions. Ao desconectar, os tokens armazenados são removidos do servidor.

8. Contato

Dúvidas sobre esta política: use o e-mail de contato informado na tela de consentimento OAuth do aplicativo.
